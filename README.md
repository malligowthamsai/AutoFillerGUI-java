# ⚡ Smart Autofill Assistant (Java Swing)

A simple Java-based desktop tool that lets you store frequently used text and quickly paste it using keyboard shortcuts.

## 🚀 Features

- Dynamic input fields (up to 10 entries)
- Assign data to shortcuts (Ctrl + 1 to Ctrl + 9)
- One-click save system
- Clean GUI using Java Swing
- Auto paste using keyboard shortcuts
- Clipboard + automation using Robot class

## 🖥 How It Works

1. Enter number of inputs  
2. Fill your data (Name, Email, Address, etc.)  
3. Click **Save Data**  
4. Click inside the shortcut area  
5. Press:
   - `Ctrl + 1` → Pastes first input  
   - `Ctrl + 2` → Pastes second input  
   - ...
